# UI_DESIGN_SYSTEM.md

## Design Philosophy

RepliCons should feel like:

* A cognitive laboratory
* A research instrument
* An advanced analytical platform

It should not feel like:

* A video game
* A cryptocurrency dashboard
* A cyberpunk nightclub

* MIT Media Lab
* Scientific Visualization Systems
* Advanced Medical Interfaces

# Layout Structure

## Main Navigation

* Dashboard
* Timeline
* Memories
* Analysis
* Personality
* Cognitive Graph
* Settings

---

## Dashboard

Display:

* Identity Stability
* Memory Density
* Emotional Diversity
* Behavioral Consistency
* Narrative Coherence

All metrics must be calculated.

No placeholder values.

No Math.random() psychology.

---

# Component Library

## Cards

Use:

* Glassmorphism (light)
* Subtle borders
* Minimal shadows

---

## Charts

Use:

* D3.js
* Recharts

Requirements:

* Interactive
* Zoomable
* Research-grade readability

---

## Timeline

Must become a flagship feature.

Capabilities:

* Year view
* Event clustering
* Emotional weighting
* Relationship highlighting

---

## Cognitive Graph

Display:

* Memory relationships
* People
* Places
* Themes
* Personality indicators
